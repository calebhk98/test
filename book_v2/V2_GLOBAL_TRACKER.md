# V2 Global Budget Tracker

## How to use

Before finalizing your chapter, check your chapter number in each section below.
If you see a **CUT** instruction, remove that element from your chapter.
If you see an **ADD** instruction, add that element.
If you see a **KEEP** instruction, that element is in budget — preserve it.
If you see a **REDUCE** instruction, trim the number of instances to the specified amount.
