## PRESENT AND CORRECT

- **Sportsbook seeded Phase A, ch07.** Ch07 text: "Sportsbook idea — Daniel watches Romans bet on chariot races. The house-edge principle clicks. One internal paragraph, maximum — a compact mental note, not a speech. Filed for later." The mental-note framing is correct; the reference also says this is only a click at ch07, with operational launch coming later. Phase A timing is right.

- **Card games spreading to city taverns by ch26.** Ch26: "Card games mentioned as going concern in city taverns." Ch31 adds a minor character playing cards or Tyche referencing card sales. Consistent with the reference's expectation of city-wide spread in Phase C.

- **Flashcard origin — Tyche's accidental invention, ch41.** Ch41: "Tyche invents them while teaching someone to read — she cuts numbered cards, puts the object name on one side and the numeral on the other. She does not recognize what she has invented. Daniel does. He funds immediate production." This matches the reference description precisely. The placement in ch41 is within the stated "Part IV-V" window (V2_MASTER_CONTEXT.md Change 5, item 7; V2_STORY_PLOT_NOTES.md beat 6: "Part IV or V").

- **Card games as divergence sign, ch44.** Ch44 explicitly requires cards to be added to the divergence-sign ledger: "card games in every tavern from Rome to Lugdunum." Matches the reference.

- **Card games ubiquitous by ch49.** Ch49 legacy inventory includes "card games ubiquitous in every tavern and market." Matches arc table's Phase E "ubiquitous" status.

- **Card games as background texture through Parts IV-V.** Ch26, ch31, ch45, ch48 all specify cards or gambling as background texture. Consistent with reference.

- **Continuity footnote present.** The cross-chapter continuity section states: "Card games / casino seeded ch16, operational ch19–22, ubiquitous by ch31, divergence sign by ch44." Correctly summarizes the arc.

- **Backgammon and latrunculi variants referenced in ch19.** Ch19 outline note reads: "Backgammon and the updated latrunculi rules visible in the background — these spread without him actively pushing them." These games are acknowledged as introduced by Daniel (the "updated" wording implies his variant) and as spreading during Phase B. See QUESTIONS item 5 for a concern about when they are actually introduced.

## QUESTIONS / AMBIGUITIES

1. **Sportsbook as "earliest passive income" vs. ch19 launch.** The reference is unambiguous that the sportsbook precedes the press, balloon money, and Macer arrangement as Daniel's first independent income. If ch19 is when operations begin (~107-108 AD), this is well after the press (operational by ch10, ~101-102 AD) and concurrent with the balloon era. The outline contradicts the reference's sequencing. Is ch19's "Sportsbook operations beginning" meant as a formal scaling of an already-running operation (in which case the launch is somewhere else and missing), or does the outline actually intend ch19 as the start?

2. **Casino operational Phase C but no chapter opens it.** The arc table says "casino operational" in Phase C (ch23-33), but no chapter entry in that range introduces the casino or assigns the Macer political consultation. If "operational" means it opens off-page between ch22 and ch23, that is a significant plot beat being elided. If it opens in one of ch23-ch33 but the outline just doesn't name it, the writing agent has no guidance.

3. **Flashcard timing: Part IV vs. ch41 (Part V).** V2_MASTER_CONTEXT.md Change 5 item 7 says "Flashcards as accidental educational byproduct (Part IV-V)." Part IV is ch32-38. The outline places Tyche's accident at ch41 (Part V, "The Ladder" section). This is within the stated range but at the far end. If the intent is Part IV, ch41 is wrong. Worth confirming whether Part IV is preferred or whether ch41 is acceptable.

4. **Lottery and roulette marked "optional" in reference but listed as required in audit spec.** V2_STORY_PLOT_NOTES.md beat list labels both as "(Part V, optional)." The audit brief treats them as required. The reference's own "optional" tag is ambiguous — the lottery's government-partnership function gives it political-cover value that makes it seem more than optional. Clarification on whether "optional" means deprioritize or genuinely skip would help.

5. **Latrunculi / tabula introduction: when does it happen?** Ch19 notes these games are "visible in the background" and "spread without him actively pushing them." But no chapter in ch16-ch18 is assigned the introduction of the Thulean variant or the backgammon rule update. If the introduction is supposed to happen between ch16 and ch19 (off-page), the reference requirement for an on-page named introduction is not met. If it happened in ch16 (bundled with card demos), the outline does not say so.

6. **Chess is in the audit spec but not in V2_STORY_PLOT_NOTES.md Section 10.** The user's audit brief lists chess as a required element with substantial detail. The reference file (Section 10) contains no mention of chess. The outline cannot be faulted for omitting chess if the reference files that writing agents use do not require it. This is either a gap in Section 10 that needs to be filled, or the chess requirement exists only in the user's spec and needs to be added to the reference files to become actionable for writing agents.

7. **Keno and word puzzles: required or discretionary?** Both are described in detail in Section 10 but do not appear in the required story beats list at the end of the section. The outline omits both. Whether this is acceptable depends on whether the reference's detail descriptions constitute requirements or options. Clarification would help.

8. **"Rough characters muscling in" — when and how?** The reference describes this as a multi-phase arc requiring Macer's muscle early, Celer's reputation in the middle, and Daniel's own security operation late. This implies it is an ongoing arc with multiple chapter beats, not a single scene. The outline assigns none of these beats. This feels like an oversight rather than a decision, but it is not clear which chapters should carry them.
