# Second naive round

Run after the change that made money real, removed the staff you used to be
handed on arrival, split the trades, and put a switch on every automatic
behaviour. The first naive round is in ../naive/.

Same rules as that round: testers are told the launch line, where to write, and
what role to play. Nothing else. No command list, no protocol document, no
examples of what to look for, because examples are a leash - a tester given ten
examples checks those ten. The game has to teach itself or it is not finished.
