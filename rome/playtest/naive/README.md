# Naive playthroughs

These testers were told three things: how to start the game, where to write
their notes, and to get as far as they could. Nothing else.

They were not given the commands. The game has to teach them, which is the
point: if the only way to learn it is for someone to hand you a protocol
document, it is not finished.

They were not allowed to read the source, the data, or any documentation in this
repository. Fog of war is on, so they could see what they had built and what
they could begin next, and nothing about where any of it led.

They were not told what to look for. Earlier rounds gave testers a list of
things to try and got back reports that covered mostly those things, which is a
property of the prompt rather than of the game. These prompts name no bug, no
mechanic and no suspicion.
