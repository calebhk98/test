# Halstead

A novel manuscript. `halstead/chapters/NN_name.md` is the only source of truth.
`halstead/HALSTEAD.md` is generated by `build_manuscript.py` and must never be
edited by hand; chapter order comes from the filenames alone.

## Subagents run on Sonnet

Spawn every subagent for this repository with `model: "sonnet"`. No exceptions,
including for prose the task treats as difficult or important.

The author's reason, verbatim: *I can tell when Opus writes it, as Opus writes
too eloquently and literary. I'm having to go back through to pull it back
towards normal human readers. The target audience is 9th graders, and the text
keeps being written for college students.*

This covers analysis agents too, not only prose agents, because an analysis
agent writes example rewrites and those get pasted into chapters.

## Before editing anything

Read `halstead/passes/HOUSE_RULES.md`. It outranks any target in any brief: a
pass that hits its number by breaking a house rule has failed and the number
gets given back. Rule 1, never talk to the reader, is the one that gets broken
most, usually as a trailing explanatory clause bolted onto a legitimate camera
observation.

## The measuring scripts, and which question each answers

Run from `halstead/`. The twelve measures live in `halstead/measures/` and
`grade.py` runs all of them; each prints a reminder to stderr if you call it
on its own, which is for reading individual hits during a fix and is never
how a pass gets judged.

| script | question |
| --- | --- |
| `grade.py` | everything below, in one report, ending in a scorecard of every measure that is not passing. Start here, and read the scorecard first. |
| `build_manuscript.py` | regenerate `HALSTEAD.md` from `chapters/` |
| `measures/check_edits.py` | em dashes, curly quotes, the paragraph convention, word count |
| `measures/prose_grade.py` | per-chapter reading grade, Lexile, sentence and paragraph shape |
| `measures/style_report.py` | conjunction rates, and the tic scan that catches the trailing explanatory clause. Takes a path. |
| `measures/tics.py` | 29 constructions against a 23-book corpus, each with a target |
| `measures/banned_phrases.py` | phrases the author has ruled out by name, checked against the chapters |
| `measures/absolutes.py` | every absolute word, all contexts, against the corpus |
| `measures/quote_length.py` | sentences per quotation against the corpus |
| `measures/number_report.py` | spelled numbers one to fifteen, all at their corpus maximum |
| `measures/dialogue_study.py`, `measures/voice_separation.py` | who sounds like whom |
| `measures/prose_check.py` | verdict language in the character sheets |
| `measures/verify_citations.py` | quotations in reference docs against the chapters |

Every script above is called by `grade.py`. Nothing measures anything unless it
is in that report: `measures/style_report.py` held the conjunction rates and the tic scan
for weeks while nothing called it, and 74 trailing explanatory clauses collected
without anyone seeing a number.

**Run the measures after a pass, not only before one.** An earlier pass in this
repository lowered the corpus maturity score from 91 to 83 and nobody noticed
until the author asked. Another broke long sentences into short ones and pushed
`sentence opens She/He + verb` from 123 to 203 per 100,000 against a target of
120. A pass is not finished until `grade.py` has run and the scorecard is no
worse than it was.

## Character sheets

`halstead/characters/_SHEET_RULES.md` is binding. No quotations, no chapter
references as the basis of a trait, no draft statistics. The test is whether the
person survives being moved to a lunar colony, a ghost story, or a Korean drama.

## Reference documents

`DOSSIER.md` and `SYNOPSIS.md` are generated by hand from the chapters and must
not cite draft versions. Audit and pass reports live in `halstead/passes/`.
