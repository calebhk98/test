Can a single Excel worksheet hold this data?

Rows per dataset vs. Excel's hard limit of 1,048,576 rows per sheet

The ONS postcode→LSOA bridge — the table required to join food-hygiene premises to neighbourhood deprivation — has 2,665,236 rows, 2.5× the worksheet limit. It cannot be opened in a sheet at all, so the central join of this project is impossible in a classic PivotTable.
