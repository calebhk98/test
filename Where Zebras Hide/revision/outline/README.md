# How the chapters get drafted

Each chapter is drafted by one Haiku agent that sees only what's listed here, not the rest of the book.

## What each drafter gets

1. `outline/chNN.md`: its own chapter. Every chapter file is self-contained. It opens with "Where things stand", which says what has happened and what Mira knows at the start.
2. `outline/BOOK_MAP.md`: where the chapter sits in the book.
3. `RULES.md`, `CHARACTERS.md`, `CREATURES.md`, `STYLE.md`.
4. The full text of the previous drafted chapter (two chapters if they're short), so the join lines up and facts stay consistent: clothes, objects, plans, what was said. The Ch 1-2 test showed a 300-word tail isn't enough: Ch 2 put Mira in boots and planned pasta, when Ch 1 had desk shoes and Thai.
5. For Chapters 1, 2, 3, 6 and 30: the old draft of that chapter, as raw material.

## What each drafter must do

- Write only its own chapter, in Mira's first person, past tense, at about the word count given.
- Follow the chapter's "Limits for this chapter". These are counts, not suggestions.
- Copy only the lines marked **verbatim**. Everything else in the outline describes intentions, not sentences.
- If a beat seems to break RULES.md, follow the rules and add a note at the end of the draft.

## Drafting order

1. Draft in order, 1 to 30, so each drafter has the previous chapter's ending.
2. If the user wants speed, chapters can be drafted in parallel in act-sized batches, then smoothed at the joins afterward.

## After drafting

Each chapter should get a check against its "Limits" and "Do not" lists before the next one starts. A Sonnet reviewer, or three Haiku, can do this.
