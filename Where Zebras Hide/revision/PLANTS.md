# Plants

This is a planning file. Drafters never receive it. Do not copy it into any packet.

In the chapter outlines, every plant is written as an ordinary present fact inside the beats. This file is the only place that says what each one is for. The outline agents add entries below, one per plant: the chapter where it is planted, what the drafter is told (as an ordinary fact), and the chapter where it pays off.
